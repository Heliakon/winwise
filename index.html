KEEP A COPY

Windows 11 backup options.

A drive can fail, a laptop can be lost, and files can be deleted by mistake. A backup is a separate copy you can get your files back from. This page covers Windows 11 only.

Which option do I need?

Files

Only my files

Documents, photos, and other personal files, kept somewhere other than the PC.

  • Windows Backup and OneDrive ↓
  • File History ↓
Whole PC

My whole PC

Windows, apps, settings, and files in one disk image, so you can get the PC back after a drive failure or a virus.

  • Disk image with Rescuezilla ↓

Keep important files in two places

For example, in OneDrive and on an external drive. If one copy is lost or damaged, you still have the other.

Restore points are not backups. They don’t keep a separate copy of your files, and they can’t help if the drive fails. Restore points are on the repair page.

Availability depends on your Windows 11 version and edition, account type, storage, and your organization’s policies. No backup is guaranteed to succeed, so check that you can get files back from yours.

01

Windows Backup and OneDrive

What it does

Windows Backup syncs the folders you choose to OneDrive and remembers supported settings and your installed apps list with your Microsoft account. On a new or reinstalled PC, you sign in and get them back.

What you need

  • A personal Microsoft account, such as an outlook.com address. The app doesn’t work with work or school accounts.
  • An internet connection.
  • Enough OneDrive storage. A free account includes 5 GB, and photos and videos fill it quickly.
Microsoft: Windows Backup ↗Microsoft: restore deleted OneDrive files ↗

Watch out

Changes and deletions sync too. If you delete or change a file on the PC, OneDrive gets the change. Deleted files stay in OneDrive’s Recycle bin only for a limited time, so OneDrive doesn’t replace an external drive.

  • When OneDrive is full, the backup stops. Check its status now and then.
  • It isn’t a copy of the whole PC. Some apps and licenses have to be installed again.
  • On a work or school PC, settings backup is a separate feature controlled by your organization.

Steps

  1. Sign in to Windows with your personal Microsoft account.
  2. Open Windows Backup from Start, or go to Settings → Accounts → Windows backup.
  3. Under Folders, turn on the folders you want to sync to OneDrive.
  4. Turn on the apps and preferences you want Windows to remember, then select Back up.
  5. Check the backup status in Windows Backup. If OneDrive reports a problem, check that you’re signed in and have enough storage.

Get things back

  • Files: sign in to OneDrive with the same Microsoft account.
  • Deleted or changed files: OneDrive’s Recycle bin and Version history keep them for a limited time, which depends on your account and settings.
  • New or reinstalled PC: during setup, sign in with the same account. If Windows finds a compatible backup, it offers to restore it.
  • Apps: your pinned apps come back as pins. Select a Microsoft Store app’s pin to install it again; for other apps, Windows directs you to the installer.
02

File History

What it does

File History copies the files in your libraries, such as Documents, Pictures, Videos, and Music, and on your Desktop to another drive. It keeps earlier versions, so you can get back a file as it was before a change or deletion.

What you need

  • An external drive or a network location with enough free space.
  • The drive connected regularly, so new copies are made.

You can also copy important folders to a separate drive yourself. Those copies don’t update, so repeat the copy after important changes.

Microsoft: File History ↗

Watch out

Restoring can replace the current version. Microsoft notes that the replacement can’t be undone. Use Restore to and choose another folder to keep both versions.

  • File History copies files only. It doesn’t copy Windows, installed apps, or their settings.

Steps: turn it on

  1. Connect an external drive, or make sure the network location is available.
  2. Open Control Panel → System and Security → File History.
  3. If the drive you want isn’t selected, choose Select drive, pick the drive, and select OK.
  4. Select Turn on.
  5. To add a folder outside your libraries, right-click it in File Explorer, select Show more options → Include in library, and choose a library.
  6. Leave the drive connected until the first backup finishes. Then reopen File History to check that a backup has completed.

Steps: restore an earlier version

  1. In File Explorer, open the folder that contains, or used to contain, the file.
  2. Right-click the folder and select Restore previous versions. If you don’t see it, select Show more options first.
  3. On the Previous Versions tab, choose a version. To look at it first, select the arrow next to Open, then Open in File History.
  4. Select the arrow next to Restore and choose Restore to. Pick another folder, so the current version stays.
03

Disk image with Rescuezilla

What it does

A disk image is a copy of your whole drive, with Windows, apps, settings, and files, saved as files on another drive. You can keep several images from different days. If the drive fails or you get a virus, you restore an image to the same drive or a new one, and the PC is back as it was on that day.

Rescuezilla is free, open-source software. It runs from a USB stick, so nothing is installed on Windows.

What you need

  • Rescuezilla 2.6.2 or newer: Rescuezilla on GitHub (2.8k stars, November 2026). Download the ISO file from Releases. Older versions may not start on PCs with Secure Boot turned on.
  • balenaEtcher, to write the ISO file to a USB stick.
  • A USB stick that can be erased. Label it “Rescuezilla” and keep it with your backup drive.
  • A backup drive with enough free space. Images are compressed and include only used space, but an image of an encrypted drive can be as large as the whole drive.
  • Your BitLocker recovery key, if Windows is encrypted. Windows may ask for it after a restore.
Rescuezilla: download and instructions ↗

Watch out

Restoring erases the drive you restore to. Check the drive’s size and name before you confirm. Choosing the wrong drive is the most serious mistake.

  • An image helps after a virus only if you made it before the infection. Keep a few images from different dates.
  • Start the PC from the USB stick with its one-time boot menu, often F8, F11, or F12. The key depends on the manufacturer.
  • If the screen is hard to read, choose Graphical fallback mode in the first menu.
  • If the drive is starting to fail, turn on the option to ignore bad sectors on the summary screen.
  • An image can take from tens of minutes to a few hours, depending on the drive and how much data you have. Use a USB 3 port.

Steps: make an image

  1. Write the Rescuezilla ISO file to the USB stick with balenaEtcher. This erases the USB stick.
  2. Connect the backup drive. Start the PC from the USB stick.
  3. Choose Start Rescuezilla, then select Backup.
  4. Select the drive with Windows, and keep all its partitions selected.
  5. Select the backup drive and a folder. The default image name includes the date.
  6. Keep the default compression, confirm, and wait until the backup finishes.
  7. Select Verify Image to check the new image. Then open a few files in Image Explorer (beta).

Steps: restore an image

  1. Start the PC from the Rescuezilla USB stick. Choose Start Rescuezilla, then select Restore.
  2. Select the backup drive and folder, then the image with the date you want.
  3. Select the drive to restore to. Check its size and name, because it will be erased.
  4. Confirm, and wait until the restore finishes.
  5. Shut down, remove the USB stick and the backup drive, then start Windows.

Restoring to a larger drive leaves extra unallocated space. You can leave it, or create a new partition on it in Disk Management. Rescuezilla’s Clone copies one drive straight to another. It’s useful for moving Windows to a new drive, but not as a backup: it keeps only one copy, erases the other drive, and you then have to swap the drives inside the PC.

Last step: check that you can get files back from your backup. Based on Microsoft and Rescuezilla documentation, checked in October and November 2026.

Windows 11 repair options.

When Windows doesn’t work properly, start with the option that changes the least. Some options remove apps or files, so read the warning before each one. This page covers Windows 11 only.

01

Open Windows Recovery Environment

What it does

Windows Recovery Environment (Windows RE) is a set of repair tools that runs outside normal Windows. Startup Repair, Uninstall Updates, System Restore, Point-in-time restore, and Reset this PC can all run from it. If Windows fails to start several times, it opens Windows RE automatically.

What you need

If your PC uses Device Encryption or BitLocker, know where to find its recovery key. Windows RE may ask for it. Check now that you can open it from another device: it’s usually in your Microsoft account, or your work or school account, or your organization’s IT team can help. Keep any copy private and somewhere secure, separate from the PC. Device Encryption is available on supported Windows 11 Home PCs too.

Microsoft: Windows Recovery Environment ↗Microsoft: Device Encryption ↗

Watch out

  • Force a shutdown only when normal startup is already failing.
  • Don’t interrupt the PC while it’s installing an update or running a repair or restore.

Ways to open it

  • From Windows: go to Settings → System → Recovery, and next to Advanced startup, select Restart now. Or hold Shift while you select Power → Restart, which also works from the sign-in screen.
  • From a USB stick: start from your installation USB and select Next → Repair my PC.
  • When normal startup is already failing: turn the PC on, and when the logo appears, hold the power button until it shuts down. Repeat once. On the third start, let it continue to Automatic Repair, then select Advanced options.
02

Fix problems using Windows Update

What it does

If Windows starts but isn’t working properly, this reinstalls the current version of Windows to repair system files and components. Your files, apps, and settings stay, so it’s the first thing to try.

What you need

  • Windows 11, version 22H2 or later, with the February 2024 optional update or a later update.
  • Windows that starts, and an internet connection.
Microsoft: reinstall through Windows Update ↗

Watch out

  • Keep the PC plugged in and connected to the internet until it finishes.
  • It may not appear on PCs managed by an organization.

Steps

  1. Go to Settings → System → Recovery.
  2. Next to Fix problems using Windows Update, select Reinstall now.
  3. Follow the prompts. Windows downloads and installs the files, then restarts.
03

Uninstall Updates

What it does

Removes a recent Windows update. Microsoft says your files and apps aren’t affected. Use it when a problem started right after an update.

What you need

  • The name or date of the update that caused the problem. Some updates can’t be uninstalled.
Microsoft: uninstall a Windows update ↗

Watch out

  • Microsoft suggests trying Fix problems using Windows Update first.
  • Removing a security update can leave the PC less protected. Microsoft advises understanding the risks first.

Steps

  • Windows starts: go to Settings → Windows Update → Update history → Uninstall updates. Next to the update, select Uninstall.
  • Windows doesn’t start: open Windows RE and select Troubleshoot → Advanced options → Uninstall Updates.
04

Startup Repair

What it does

Startup Repair tries to fix problems that stop Windows from starting, such as damaged system files or boot settings. If it can’t fix the problem, it shows a report of what it found.

What you need

  • Access to Windows RE.
  • Your BitLocker recovery key, if the drive is encrypted.
Microsoft: Startup Repair ↗

Watch out

  • If Startup Repair doesn’t help, Microsoft suggests System Restore.

Steps

  1. Open Windows RE.
  2. Select Troubleshoot → Advanced options → Startup Repair.
  3. Follow the prompts and let it finish.
05

System Restore

What it does

System Restore rolls back system files, registry settings, and installed programs to an earlier restore point. Microsoft says it doesn’t affect your personal files, which also means it doesn’t back them up.

Windows also creates restore points automatically. Older points can be removed as Windows manages the space you allowed, so a named point might not be available later.

What you need

  • System Protection turned on for the Windows drive.
  • A restore point made before the problem started.
  • Administrator access, which may be needed.
Microsoft: create a restore point ↗Microsoft: System Restore ↗

Watch out

  • Apps, drivers, and updates installed after the restore point can be removed.
  • It isn’t a backup. Restore points are on the same drive and don’t include your personal files.
  • If the drive is encrypted, Windows RE may ask for your BitLocker recovery key.

Steps: create a restore point

  1. Open Start, search for Create a restore point, and open the matching result.
  2. On the System Protection tab, select the Windows drive, usually C:.
  3. If protection is off for that drive, select Configure, choose Turn on system protection, use the slider to allow disk space, then select Apply → OK.
  4. Select Create, enter a name you’ll recognize, such as Before graphics driver update, and select Create.

Steps: restore

  • Windows starts: press Windows logo key + R, type rstrui.exe, and press Enter. Choose a restore point, optionally select Scan for affected programs, then Next → Finish.
  • Windows doesn’t start: open Windows RE and select Troubleshoot → Advanced options → System Restore.
06

Point-in-time restore

What it does

When it’s on, Windows creates restore points automatically, about every 24 hours by default, and keeps each one for up to 72 hours. Restoring a point returns the whole Windows drive to that moment, including your local files.

What you need

  • Windows 11, version 24H2 or later, on a supported device.
  • The feature turned on. Microsoft turns it on by default on Home devices, and on Pro devices not managed by an organization, when the Windows volume is 200 GB or larger (its size, not its free space). On a smaller volume, turn it on yourself. On an organization-managed device, check the setting and follow your organization’s policy.
  • Enough free disk space.
Microsoft: Point-in-time restore ↗Microsoft: Point-in-time restore technical details ↗

Watch out

Everything on the Windows drive returns to the selected point. Files, apps, settings, and passwords changed after it are lost. If you can still reach important newer files, copy them to another drive or to cloud storage first.

  • Restore points are on the same drive, so they can’t help if the drive fails.
  • Windows removes points when they expire, when they reach their storage limit, or when free space drops to 20 GB or less.
  • After restoring, install Windows updates again. Restoring can undo recent security updates.
  • To go back further than about three days, use System Restore.

Steps: check that it’s on

  1. Go to Settings → System → Recovery → Point-in-time restore → View or edit, and approve the administrator prompt.
  2. Check that the feature is on, and look at the available restore points. If you just turned it on, check again later to confirm that one has been created.

Steps: restore a point

  1. Open Windows RE and select Troubleshoot → Point-in-time restore.
  2. Enter your BitLocker recovery key if asked, choose a restore point, and select Continue.
  3. Review the point, Windows version, and data-loss warning, then select Restore. Keep the PC plugged in until it restarts into Windows.
07

Reset this PC

What it does

Reset this PC reinstalls Windows using the PC’s own recovery tools. You choose whether to keep your personal files. Either way, your installed apps and settings are removed.

Keep my files

Personal files: kept.
Apps and settings: removed. Some manufacturer apps or customizations may be restored, depending on the options you choose.

Remove everything

Personal files: removed.
Apps and settings: removed. Use this for a fresh start. Before giving the PC away, also turn on Clean data, which makes removed files harder to recover.

What you need

  • A list of the apps you’ll need to reinstall, with their installers and licenses.
  • An internet connection, if you choose Cloud download.
Microsoft: reset your PC ↗Microsoft: recovery options ↗

Watch out

Remove everything deletes your personal files. Back up first: see the backup options.

Don’t restart the PC during a reset. Microsoft notes that the screen can stay black for a long time, sometimes more than 15 minutes, and the PC may restart by itself. Restarting it yourself can make the reset fail.

Steps

  1. If Windows starts: go to Settings → System → Recovery and, next to Reset this PC, select Reset PC.
    If Windows doesn’t start: open Windows RE and select Troubleshoot → Reset this PC.
  2. Choose Keep my files or Remove everything.
  3. Choose Cloud download or Local reinstall.
  4. Review the summary of what will happen, then select Reset. Keep the PC plugged in.

Cloud download downloads fresh Windows installation files from Microsoft. It isn’t a cloud backup of your files. Local reinstall uses files already on the PC; if it fails, try Cloud download.

08

Windows 11 installation USB

What it does

An installation USB can open the recovery tools, reinstall Windows while keeping your files and apps, or install a fresh copy. You can make it in advance, or on another working PC when you need it.

What you need

  • A blank USB stick of at least 8 GB. It will be erased.
  • A working Windows PC to make it.
  • For most PCs, Microsoft’s Media Creation Tool, which makes media for x64 PCs. For Windows on Arm, use Microsoft’s Windows 11 Arm64 download, which may need drivers from your PC’s manufacturer to start, or your manufacturer’s recovery media.

For the best driver compatibility on any PC, Microsoft suggests checking whether your manufacturer offers its own recovery media.

Microsoft: create installation media ↗Microsoft: reinstall with installation media ↗

Watch out

Making the USB erases everything on it. Copy anything you need from the USB stick first.

Steps: make the USB

  1. On a working Windows PC, go to Microsoft’s Download Windows 11 page. Under Create Windows 11 Installation Media, select Download now.
  2. Run the Media Creation Tool, approve the administrator prompt, and accept the license terms.
  3. Choose the language and edition, select USB flash drive, pick your USB stick, and let the tool finish.

Three ways to use it

1. Repair without reinstalling

Files, apps, settings: depend on the tool you choose

Start the PC from the USB stick. On the first Windows Setup screen, select Next, then Repair my PC. This opens recovery tools such as Startup Repair and System Restore. Opening them changes nothing by itself.

2. Reinstall and keep everything

Files, apps, settings: kept

Only if Windows still starts. Open the USB stick in File Explorer and run setup.exe. Select Change what to keep, choose Keep personal files and apps, then select Next and Install. Use media for the same edition as your installed Windows. If Keep personal files and apps isn’t offered, stop unless you’re ready to reinstall your apps.

3. Clean install

Files, apps, settings: removed

A clean install removes your personal files, apps, settings, and manufacturer customizations. Back up your files first, then disconnect the drives with your backups.

Start the PC from the USB stick, select Install Windows 11, and confirm that everything will be deleted. Choose the edition that matches your license. Where Setup lists partitions, delete only those on Disk 0, then install to Disk 0 Unallocated Space.

Don’t change partitions on any other disk, such as Disk 1. On a PC with more than one drive, that can erase a data drive.

Starting from the USB stick: if Windows runs, go to Settings → System → Recovery → Advanced startup → Restart now, then select Use a device. Otherwise use your PC’s boot menu key while it starts; the key varies by manufacturer. A PC that was activated before normally reactivates after reinstalling the same edition.

09

Recovery Drive

What it does

A Recovery Drive is a USB stick made on your PC while it works. It can open Windows RE and reinstall Windows. It includes the built-in Windows files, updates installed when you made it, and any customizations from your PC’s manufacturer, and it’s meant for that PC.

What you need

  • A USB stick that can be erased.
  • A PC that still works. Microsoft recommends making one in advance, as a last-resort option.
Microsoft: Recovery Drive ↗

Watch out

Creating a Recovery Drive erases existing data on the selected USB drive. Copy anything you need from it first.

  • It contains no backup of your personal files. Reinstalling with Recover from a drive removes files, apps, and settings.
  • Recreate it once a year so it includes recent updates.

Steps

  1. Search Start for Recovery Drive and open it. Approve the administrator prompt if Windows asks.
  2. Keep Back up system files to the recovery drive selected, then select Next.
  3. Connect the USB stick, select it, then select Next and Create. Copying can take a while.

Based on Microsoft documentation, checked in October and November 2026. Menu names and availability can change with Windows 11 updates.
