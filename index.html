BEFORE YOU MAKE A CHANGE

How to back up your OS.

Before changing any service, create a Windows System Restore point. It can help you recover system settings if a change prevents normal startup or sign-in.

01

Create “Before Winwise”

  1. Open Start, search for Create a restore point, and open the matching result.
  2. In System Protection, select your Windows drive — usually C:.
  3. Select Create, name the restore point Before Winwise, then select Create again. Wait for the success message before changing services.

Is Create greyed out?

Select the Windows drive, choose Configure → Turn on system protection, allow disk space using the slider, then choose Apply → OK. Try Create again.

Microsoft: create a restore point ↗
02

Why you need both backups

Your JSON backup is a scalpel — it reverts only the services you changed. A restore point is the safety net when you can’t reach PowerShell at all.

Winwise JSON backup

Restores the recorded startup settings and attempts the previous running state for the services in that backup. Use it with your downloaded script when you can run PowerShell.

Windows restore point

Rolls back system files, registry settings, and installed programs. It can be applied from Windows Recovery Environment.

A restore point is not a full disk backup and does not back up your personal files. Keep a separate copy of important files. System Restore is one recovery option; a restore point may be unavailable or fail.

03

If Windows won’t boot or sign in

  1. If the sign-in screen is available, hold Shift while selecting Power → Restart.
  2. In the recovery menu, select Troubleshoot → Advanced options → System Restore.
  3. Choose Before Winwise. Use Show more restore points if needed, review affected programs, then select Next → Finish. Let recovery complete, then restart.
Can’t reach the sign-in screen?

When normal startup is already failing: turn the PC on and wait for the Windows or manufacturer logo, then hold the power button to shut it down. Repeat this interruption once more. On the third start, let it continue; Windows should open Automatic Repair. Select Advanced options, then follow the recovery menu above. Avoid forcing a shutdown during an update or a restore.

Have your BitLocker recovery key ready

If the Windows drive is encrypted, System Restore in recovery requires the key. Keep it accessible from another device before making changes. Microsoft’s recovery guide includes a link to find your key.

If the point is missing or recovery does not work, Windows RE also offers Startup Repair; Windows installation media can provide another route to recovery tools.
