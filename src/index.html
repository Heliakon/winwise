PREPARE FOR THE UNEXPECTED

How to back up your OS.

A drive can fail, a laptop can be lost, or Windows can stop starting normally. This guide covers Windows 11 only. It answers two questions: how to keep a copy of your files, and how to get Windows working again, with what happens to your personal files at each step.

What do you need?

Back up my files

Keep a copy of your documents, photos, and other files somewhere other than the PC.

A practical combination

  • Keep a copy of important files away from the PC: on another drive with File History, or in cloud storage.
  • Keep System Restore turned on, and check whether your PC has Point-in-time restore.
  • While the PC works, make a Windows 11 installation USB or a Recovery Drive. Your PC’s manufacturer may also offer recovery media with its own drivers.
  • If your PC uses Device Encryption or BitLocker, know where to find its recovery key.

Availability depends on your Windows 11 version and edition, installed updates, account type, storage, administrator access, and your organization’s policies. Menu names can differ slightly between builds. No backup or recovery method is guaranteed to succeed, so it helps to have more than one.

This is what each option is designed to do when it completes successfully. It isn’t a guarantee against a failing drive or an interrupted recovery, so back up files you can’t replace first.

Prepare

Back up my files

01

File History: back up personal files

File History saves copies of the files in your libraries, such as Documents, Pictures, Videos, and Music, and on your Desktop. It keeps earlier versions, so you can get back a file as it was before a change or deletion.

Protects
Personal files in your libraries and on your Desktop
Stored
An external drive or a network location
Personal files
Copies and earlier versions, for the included folders only
You need
A drive or network location with enough free space
Useful when
A file is deleted or overwritten, or the PC’s drive fails

File History is a file backup. It doesn’t copy Windows, installed programs, or their settings. You can also copy important folders to a separate drive yourself; those copies don’t update, so repeat the copy after important changes.

Microsoft: File History ↗

Turn on File History

  1. Connect an external drive, or make sure the network location you want to use is available.
  2. Open Control Panel → System and Security → File History.
  3. If the drive you want isn’t selected, choose Select drive, pick the drive, and select OK. Then select Turn on.
  4. Check which folders are covered: your libraries and Desktop. To add another folder, right-click it in File Explorer, select Show more options → Include in library, and choose a library.
  5. Leave the drive connected until the first backup finishes, then reopen File History to check that a backup has completed.

Restore an earlier version

  1. In File Explorer, open the folder that contains, or used to contain, the file.
  2. Right-click the folder and select Restore previous versions. If you don’t see it, select Show more options first.
  3. On the Previous Versions tab, choose a version. To look at it first, select the arrow next to Open, then Open in File History.
  4. Select Restore, or select the arrow next to it and choose Restore to to save the version somewhere else.

Restoring replaces the current version. Microsoft notes that the replacement can’t be undone. To keep both versions, use Restore to and choose another location.

02

Windows Backup and OneDrive

The Windows Backup app can sync selected folders to OneDrive and remember supported settings and app information with your Microsoft account. It helps you get set up again on a new or reinstalled PC.

Protects
Selected folders, supported Windows settings, and information about your apps
Stored
OneDrive and your Microsoft account
Personal files
Selected folders, such as Desktop, Documents, and Pictures, kept in sync with OneDrive
You need
A personal Microsoft account, an internet connection, and enough OneDrive storage
Useful when
You move to a new PC, reinstall Windows, or want your files on more than one device

Windows Backup isn’t a complete system image. It doesn’t guarantee that every app, license, setting, or file comes back automatically. On a work or school PC, settings backup is a separate feature controlled by your organization.

Microsoft: Windows Backup ↗Microsoft: restore deleted OneDrive files ↗Microsoft: settings backup for organizations ↗

Set up Windows Backup

  1. Sign in to Windows with a personal Microsoft account, such as an outlook.com address. The consumer app doesn’t work with work or school accounts.
  2. Open Windows Backup from Start, or go to Settings → Accounts → Windows backup.
  3. Under Folders, choose which folders to sync to OneDrive.
  4. Choose the apps and preferences you want Windows to remember, then select Back up.
  5. Check the backup status in Windows Backup or in Settings → Accounts → Windows backup. If OneDrive reports a problem, check that you’re signed in and have enough storage.

OneDrive can keep a cloud copy of synced files. Changes and deletions can also sync, so keep another backup of files you cannot replace.

Get things back

  • Files: sign in to OneDrive with the same Microsoft account to get to your synced folders.
  • Deleted or changed files: OneDrive’s Recycle bin can bring back deleted files, and Version history can bring back an earlier version of a file. Both keep items only for a limited time, which depends on your account and settings.
  • New or reinstalled PC: during setup, sign in with the same account. If Windows finds a compatible backup, it offers to restore your supported settings and app information.
  • Apps: your pinned apps come back as pins. Microsoft Store apps can be reinstalled by selecting their pins; for other apps, Windows directs you to download the installer.

03

Fix problems using Windows Update

If Windows still starts but isn’t working properly, this reinstalls the current version of Windows to repair system components. It keeps your files, apps, and settings, so it’s a good first step before anything more drastic.

Personal files
Kept
Apps and settings
Kept
You need
Windows 11, version 22H2 or later with the February 2024 optional update or a later update, Windows that starts, and an internet connection. It may not appear on PCs managed by an organization.
Useful when
Windows starts but system files or components seem damaged, especially after an update
Microsoft: reinstall through Windows Update ↗
  1. Go to Settings → System → Recovery.
  2. Next to Fix problems using Windows Update, select Reinstall now.
  3. Follow the prompts. Windows downloads and installs the files, then restarts. Keep the PC plugged in.
04

System Restore

System Restore rolls back system files, registry settings, and installed programs to an earlier restore point. Microsoft says it doesn’t affect your personal files, which also means it doesn’t back them up.

Stored
On the same PC, in disk space you allow on the protected drive
Personal files
Kept unchanged; not part of the restore point
Apps and settings
Rolled back. Apps, drivers, and updates installed after the point can be removed.
You need
System Protection turned on for the Windows drive, and a restore point. Administrator access may be needed.
Useful when
Windows misbehaves after an app, driver, update, or settings change

Windows also creates restore points automatically. Older points can be removed as Windows manages the space you allowed, so a named point might not be available later.

Microsoft: create a restore point ↗Microsoft: System Restore ↗

Create a restore point

  1. Open Start, search for Create a restore point, and open the matching result.
  2. On the System Protection tab, select the Windows drive, usually C:.
  3. If protection is off for that drive, select Configure, choose Turn on system protection, use the slider to allow disk space, then select Apply → OK.
  4. Select Create, enter a name you’ll recognize, such as Before graphics driver update, and select Create.

Restore

  • Windows starts: press Windows logo key + R, type rstrui.exe, and press Enter. Choose a restore point, optionally select Scan for affected programs, then Next → Finish.
  • Windows doesn’t start: open Windows RE and select Troubleshoot → Advanced options → System Restore.
05

Point-in-time restore

Point-in-time restore is separate from System Restore. When it’s on, Windows creates restore points automatically, about every 24 hours by default, and normally keeps each one for up to 72 hours. Restoring a point rolls back the whole Windows drive, including your local files.

Stored
On the same PC, for up to 72 hours; points can be removed sooner when storage runs low
Personal files
Rolled back. Local files on the Windows drive return to the selected point; newer files and changes are lost. Other drives aren’t restored, and Microsoft says files in cloud services such as OneDrive aren’t affected.
Apps and settings
Rolled back
You need
A supported device with Windows 11, version 24H2 or later, the feature turned on, and enough free disk space
Useful when
Something went wrong in the last few days and you want the whole PC back as it was

On Home devices, and on Pro devices not managed by an organization, Microsoft says it’s on by default only when the Windows volume is 200 GB or larger (its size, not its free space). On a smaller volume you can turn it on yourself. Microsoft’s documentation currently differs about the default on organization-managed devices running 26H2, so check the setting and follow your organization’s policy.

Microsoft: Point-in-time restore ↗Microsoft: Point-in-time restore technical details ↗

Check that it’s on

  1. Go to Settings → System → Recovery → Point-in-time restore → View or edit, and approve the administrator prompt.
  2. Check that the feature is on, and look at the available restore points. If you just turned it on, check again later to confirm that one has been created.

Points are created on a schedule, not on demand. Windows removes them when they expire, when they reach their storage limit, or when free space drops to 20 GB or less. It’s short-term protection, not a replacement for a file backup.

Restore a point

Everything on the Windows drive returns to the selected point. Local files, apps, settings, and passwords changed after it are lost. If you can still reach important newer files, copy them to another drive or to cloud storage first.

  1. Open Windows RE and select Troubleshoot → Point-in-time restore.
  2. Enter your BitLocker recovery key if asked, choose a restore point, and select Continue.
  3. Review the point, Windows version, and data-loss warning, then select Restore. Keep the PC plugged in until it restarts into Windows.

If Point-in-time restore isn’t available, or you need to go back further than about three days, Microsoft suggests System Restore instead.

06

Reset this PC

Reset this PC reinstalls Windows using the PC’s own recovery tools. You choose whether to keep your personal files. Either way, your installed apps and settings are removed. Microsoft suggests trying the less disruptive options above first.

Keep my files

Personal files: kept.
Apps and settings: removed. Some manufacturer apps or customizations may be restored, depending on the options you choose.

Remove everything

Personal files: removed.
Apps and settings: removed. Use this for a fresh start. Before giving the PC away, also turn on Clean data, which makes removed files harder to recover.

Microsoft: reset your PC ↗Microsoft: recovery options ↗
  1. If Windows starts: go to Settings → System → Recovery and, next to Reset this PC, select Reset PC.
    If Windows doesn’t start: open Windows RE and select Troubleshoot → Reset this PC.
  2. Choose Keep my files or Remove everything.
  3. Choose Cloud download or Local reinstall.
  4. Review the summary of what will happen, then select Reset. Keep the PC plugged in.

Don’t restart the PC during a reset. Microsoft notes that the screen can stay black for a long time, sometimes more than 15 minutes, and the PC may restart by itself. Restarting it yourself can make the reset fail.

Cloud download downloads fresh Windows installation files from Microsoft. It isn’t a cloud backup of your files. Local reinstall uses files already on the PC; if it fails, try Cloud download.

Make a list of the apps you’ll need to reinstall, and have your installers and licenses ready.

07

Windows 11 installation USB

An installation USB is the most useful thing to have when Windows won’t start. You can make it in advance, or on another working PC when you need it. It can open the recovery tools, reinstall Windows while keeping your files, or install a fresh copy.

Make the USB

Making the USB erases everything on it. Use a blank USB drive of at least 8 GB, or copy anything you need from it first.

  1. On a working Windows PC, go to Microsoft’s Download Windows 11 page. Under Create Windows 11 Installation Media, select Download now.
  2. Run the Media Creation Tool, approve the administrator prompt, and accept the license terms.
  3. Choose the language and edition, select USB flash drive, pick your USB drive, and let the tool finish.

The Media Creation Tool makes media for x64 PCs. If your PC runs Windows on Arm, use Microsoft’s Windows 11 Arm64 download, which may need drivers from your PC’s manufacturer to start, or use your manufacturer’s recovery media. For the best driver compatibility on any PC, Microsoft suggests checking whether your manufacturer offers its own recovery media.

Microsoft: create installation media ↗Microsoft: reinstall with installation media ↗Microsoft: Recovery Drive ↗

Three ways to use it

1. Repair without reinstalling

Files, apps, settings: depend on the tool you choose

Start the PC from the USB. On the first Windows Setup screen, select Next, then Repair my PC. This opens recovery tools such as Startup Repair and System Restore. The tools offered can differ from those on the PC’s own recovery menu. Opening them changes nothing by itself.

2. Reinstall and keep everything

Files, apps, settings: kept

Only if Windows still starts. Open the USB in File Explorer and run setup.exe. Select Change what to keep, choose Keep personal files and apps, then select Next and Install. Use media for the same edition as your installed Windows. If Keep personal files and apps isn’t offered, stop unless you’re ready to reinstall your apps.

3. Clean install

Files, apps, settings: removed

A clean install removes your personal files, apps, settings, and manufacturer customizations. Back up your files first.

Start the PC from the USB, select Install Windows 11, and confirm that everything will be deleted. Choose the edition that matches your license. Where Setup lists partitions, delete only those on Disk 0, then install to Disk 0 Unallocated Space.

Don’t change partitions on any other disk, such as Disk 1. On a PC with more than one drive, that can erase a data drive.

Starting from the USB: if Windows runs, go to Settings → System → Recovery → Advanced startup → Restart now, then select Use a device. Otherwise use your PC’s boot menu key while it starts; the key varies by manufacturer. A PC that was activated before normally reactivates after reinstalling the same edition.

Alternative: Recovery Drive

A Recovery Drive is a USB drive made on your PC. It includes the built-in Windows files, updates installed when you made it, and any customizations from your PC’s manufacturer, and it’s meant for that PC. Microsoft recommends making one while your PC works, as a last-resort option. It contains no backup of your personal files: reinstalling with Recover from a drive removes files, apps, and settings. It can also open the recovery tools.

Creating a Recovery Drive erases existing data on the selected USB drive. Copy anything you need from it first.

  1. Search Start for Recovery Drive and open it. Approve the administrator prompt if Windows asks.
  2. Keep Back up system files to the recovery drive selected, then select Next.
  3. Connect the USB drive, select it, then select Next and Create. Copying can take a while.

Microsoft recommends recreating it once a year so it includes recent updates.

08

Full system images

A system image is a copy of whole drives or partitions, saved to another drive, so you can restore the PC as a whole after a drive fails or is replaced.

Stored
An external drive or another location your backup tool supports
Personal files
Files on restored partitions return to the image’s state. Newer files there are overwritten.
Apps and settings
Windows, apps, and settings on restored partitions return to the image’s state
You need
A backup tool, enough storage on another drive, and a way to start the restore
Useful when
A drive fails or is replaced and you want the whole system back, not just files
Microsoft: deprecated features ↗Microsoft: create a system image ↗

For full-disk backups, Microsoft suggests a product from another software publisher. Winwise doesn’t recommend a specific one. Before you choose, check its Windows 11 support, how recovery works (including whether you need its own recovery media), and its pricing. Whichever tool you use, confirm that backups complete, and know how you’d start a restore before you need it.

Legacy built-in tool: Backup and Restore (Windows 7)

Despite its name, this tool can still appear in Windows 11. Microsoft lists System Image Backup as deprecated: it’s no longer developed and might be removed in a future update, but it hasn’t been removed yet.

  1. Connect an external drive with enough free space.
  2. Open Control Panel → System and Security → Backup and Restore (Windows 7), and select Create a system image.
  3. Choose where to save it, then follow the steps.
  4. To restore, open Windows RE, select Troubleshoot → Advanced options, and look for System Image Recovery. On some PCs it appears only after you select See more recovery options.

Microsoft’s support pages list System Image Recovery among the Windows RE tools, but a Microsoft technical reference describes it as available on Windows Server editions only. Check that you can find it on your PC before you rely on the image.

09

Open Windows Recovery Environment

Windows Recovery Environment (Windows RE) is where System Restore, Point-in-time restore, Reset this PC, and the other recovery tools run when Windows can’t. If Windows fails to start several times, it opens Windows RE automatically.

If your PC uses Device Encryption or BitLocker, know where to find its recovery key. Windows may ask for it when you use recovery tools. Check now that you can open it from another device: it’s usually in your Microsoft account, or your work or school account, or your organization’s IT team can help. Keep any copy private and somewhere secure, separate from the PC. Device Encryption is available on supported Windows 11 Home PCs too.

Microsoft: Windows Recovery Environment ↗Microsoft: Device Encryption ↗
  • From Windows: go to Settings → System → Recovery, and next to Advanced startup, select Restart now. Or hold Shift while you select Power → Restart, which also works from the sign-in screen.
  • From a USB: start from your installation USB and select Next → Repair my PC.
  • Only if normal startup is already failing: turn the PC on, and when the logo appears, hold the power button until it shuts down. Repeat once. On the third start, let it continue to Automatic Repair, then select Advanced options. Don’t interrupt the PC while it’s installing an update or running a restore.

Two other tools are in Troubleshoot → Advanced options. Startup Repair tries to fix common problems that stop Windows from starting. Uninstall Updates removes a recent update; Microsoft says your files and apps aren’t affected.
