PREPARE FOR THE UNEXPECTED

How to back up your OS.

A drive can fail, a laptop can be lost, or Windows can stop starting normally. Windows 11 includes tools for each of these situations. A good plan usually combines a separate copy of your personal files with a way to restore or reinstall Windows.

Choose what to set up

Each option protects something different. File backups keep copies of your files somewhere else. Recovery points roll Windows back on the same PC. Recovery media and system images help when the PC can’t start or a drive needs replacing.

  • 01File backup

    File History

    Saves copies and earlier versions of your personal files to another drive or a network location.

    Personal files: yes, in the folders it covers.

    File History steps ↓
  • 02Cloud sync and settings

    Windows Backup and OneDrive

    Syncs selected folders to OneDrive and remembers supported settings and app information for a new or reinstalled PC.

    Personal files: selected folders, through sync.

    Windows Backup steps ↓
  • 03Local recovery point

    System Restore

    Rolls back system files, registry settings, and installed programs to a restore point on the same PC.

    Personal files: not changed, and not backed up.

    System Restore steps ↓
  • 04Short-term recovery point

    Point-in-time restore

    Rolls back the whole Windows volume to an automatic point from the last few days, on supported Windows 11 PCs.

    Personal files: local files on that volume roll back too.

    Point-in-time restore steps ↓
  • 05Recovery media

    Recovery Drive

    A USB drive that starts recovery tools and can reinstall Windows when the PC won’t start.

    Personal files: not included; reinstalling removes them.

    Recovery Drive steps ↓
  • 06System image

    Full system image

    A broader copy of Windows and its system partitions, saved to another drive, for restoring the PC as a whole.

    Personal files: included if they’re on an imaged drive.

    System image steps ↓

A practical combination

  • Keep a copy of important files away from the PC: on another drive, with File History, or in cloud storage.
  • Keep System Restore turned on, and check whether your PC has Point-in-time restore.
  • Create a Recovery Drive while the PC is working.
  • Know where to find your BitLocker recovery key.

Need to recover now? Open Windows RE and choose a tool.

Availability depends on your Windows version and edition, installed updates, account type, storage, administrator access, and your organization’s policies. Menu names can differ slightly between builds. No backup or recovery method is guaranteed to succeed, so it helps to have more than one.

01

File History: back up personal files

File History saves copies of the files in your libraries, such as Documents, Pictures, Videos, and Music, and on your Desktop. It keeps earlier versions, so you can get back a file as it was before a change or deletion.

Protects
Copies and earlier versions of files in the included folders
Stored
An external drive or a network location
Personal files
Yes, for the included folders only
You need
A drive or network location with enough free space
Useful when
A file is deleted or overwritten, or the PC’s drive fails

Turn on File History

  1. Connect an external drive, or make sure the network location you want to use is available.
  2. Open Control Panel → System and Security → File History.
  3. If the drive you want isn’t selected, choose Select drive, pick the drive, and select OK. Then select Turn on.
  4. Check which folders are covered: your libraries and Desktop. To add another folder, right-click it in File Explorer, select Show more options → Include in library, and choose a library.
  5. Leave the drive connected until the first backup finishes, then reopen File History to check that a backup has completed.

Restore an earlier version

  1. In File Explorer, open the folder that contains, or used to contain, the file.
  2. Right-click the folder and select Restore previous versions. If you don’t see it, select Show more options first.
  3. On the Previous Versions tab, choose a version. To look at it first, select the arrow next to Open, then Open in File History.
  4. Select Restore, or select the arrow next to it and choose Restore to to save the version somewhere else.

Restoring replaces the current version. Microsoft notes that the replacement can’t be undone. To keep both versions, use Restore to and choose another location.

File History is a file backup. It doesn’t copy Windows, installed programs, or their settings. You can also copy important folders to a separate drive yourself; those copies don’t update, so repeat the copy after important changes.

02

Windows Backup and OneDrive

The Windows Backup app can sync selected folders to OneDrive and remember supported settings and app information with your Microsoft account. It helps you get set up again on a new or reinstalled PC.

Protects
Selected folders, supported Windows settings, and information about your apps
Stored
OneDrive and your Microsoft account
Personal files
Selected folders, such as Desktop, Documents, and Pictures, kept in sync with OneDrive
You need
A personal Microsoft account, an internet connection, and enough OneDrive storage
Useful when
You move to a new PC, reinstall Windows, or want your files on more than one device

Set up Windows Backup

  1. Sign in to Windows with a personal Microsoft account, such as an outlook.com address. The consumer app doesn’t work with work or school accounts.
  2. Open Windows Backup from Start, or go to Settings → Accounts → Windows backup.
  3. Under Folders, choose which folders to sync to OneDrive.
  4. Choose the apps and preferences you want Windows to remember, then select Back up.
  5. Check the backup status in Windows Backup or in Settings → Accounts → Windows backup. If OneDrive reports a problem, check that you’re signed in and have enough storage.

Sync isn’t a separate copy. Changes and deletions in a synced folder can sync to OneDrive and your other devices. OneDrive’s recycle bin can help for a limited time, but keep a separate copy of files you can’t replace.

Get things back

  • Files: sign in to OneDrive with the same Microsoft account to get to your synced folders.
  • New or reinstalled PC: during setup, sign in with the same account. If Windows finds a compatible backup, it offers to restore your supported settings and app information.
  • Apps: your pinned apps come back as pins. Microsoft Store apps can be reinstalled by selecting their pins; for other apps, Windows directs you to download the installer.

Windows Backup isn’t a complete system image. It doesn’t guarantee that every app, license, setting, or file comes back automatically. Microsoft Edge uses its own sync for favorites. On a work or school PC, Windows settings backup and restore is a separate feature; whether it’s available, and what it restores, depends on your organization’s policies.

03

System Restore: create a restore point

System Restore can roll back system files, registry settings, and installed programs to an earlier restore point. Microsoft says it doesn’t affect your personal files, which also means it doesn’t back them up.

Protects
System files, registry settings, and installed programs
Stored
On the same PC, in disk space you allow on the protected drive
Personal files
Not changed by a restore, and not backed up
You need
System Protection turned on for the Windows drive; administrator access may be needed
Useful when
Windows misbehaves after an app, driver, update, or settings change

Create a restore point

  1. Open Start, search for Create a restore point, and open the matching result.
  2. On the System Protection tab, select the Windows drive, usually C:.
  3. If protection is off for that drive, select Configure, choose Turn on system protection, use the slider to allow disk space, then select Apply → OK.
  4. Select Create, enter a name you’ll recognize, such as Before graphics driver update, and select Create. Wait for the message that the restore point was created.

Windows also creates restore points automatically when needed. Restore points share the space you allowed, and older ones can be removed as Windows manages that space, so a named point might not be available later.

Use a restore point while Windows is running

  1. Open Control Panel, search for Recovery, and select Open System Restore. You can also press Windows logo key + R, type rstrui.exe, and press Enter.
  2. Select Next and choose a restore point. To see which programs and drivers could change, select Scan for affected programs.
  3. Select Next → Finish, and let the restore complete.

If Windows can’t start normally, you can run System Restore from Windows Recovery Environment instead. See the recovery steps.

04

Point-in-time restore: short-term rollback

Point-in-time restore is a newer feature, separate from System Restore. When it’s turned on, Windows creates local restore points automatically, about every 24 hours by default, and normally keeps each one for up to 72 hours. Restoring a point rolls back the whole Windows volume.

Protects
The Windows volume: Windows, apps, settings, and local files
Stored
On the same PC, for up to 72 hours; points can be removed sooner when storage runs low
Personal files
Local files on the Windows volume roll back too. Other volumes aren’t restored, and Microsoft says files stored in cloud services such as OneDrive aren’t affected.
You need
A supported device with Windows 11, version 24H2 or later, the feature turned on, and enough free disk space
Useful when
Something went wrong in the last few days and you want the whole PC back as it was

The feature isn’t exclusive to version 26H2. On Home devices, and on Pro devices that aren’t joined to a domain or managed by an organization, Microsoft says it’s on by default only when the Windows OS volume is 200 GB or larger. That is the size of the volume Windows is installed on, not its free space. On a smaller volume, you can turn the feature on yourself.

Microsoft’s documentation currently differs about the default on organization-managed devices running 26H2. If your device is managed by your work or school, check the setting and follow your organization’s policy.

Check Point-in-time restore

  1. Go to Settings → System → Recovery → Point-in-time restore → View or edit.
  2. If Windows asks for administrator permission, approve it. Only local administrators can view or change these settings.
  3. Check that the feature is on, and look at the available restore points and their dates and times.
  4. If you just turned it on, don’t assume a point exists yet. Check again later to confirm that one has been created.

Restore points are created on a schedule, not on demand. Windows removes them, oldest first, when they pass their retention period, when restore points reach their storage limit, or when free disk space drops to 20 GB or less. Point-in-time restore is short-term protection; it doesn’t replace a file backup on another drive or a full system image.

Restoring a point is done from Windows Recovery Environment. See the recovery steps and warning.

05

Recovery Drive and BitLocker recovery key

A Recovery Drive is a USB drive that can start your PC into Windows Recovery Environment, give you access to recovery tools, and reinstall Windows. It’s intended for the PC it was created on.

Protects
Access to recovery tools, plus the Windows files and updates installed when the drive was made
Stored
A USB drive
Personal files
Not included. Reinstalling Windows from it removes personal files, apps, and settings.
You need
A USB drive whose contents can be erased
Useful when
Windows can’t start and the built-in recovery menu isn’t reachable

Create a Recovery Drive

Creating a Recovery Drive erases existing data on the selected USB drive. Copy anything you need from it first.

  1. Search Start for Recovery Drive and open it. Approve the administrator prompt if Windows asks.
  2. Keep Back up system files to the recovery drive selected, then select Next.
  3. Connect the USB drive, select it, and select Next.
  4. Select Create. Copying the files can take a while.

Microsoft recommends recreating the drive once a year so it includes recent Windows updates. Label the drive and store it somewhere safe. To use it, start the PC from the USB drive; how to do that varies by manufacturer.

Know where your BitLocker recovery key is

If your device is encrypted, Windows Recovery Environment may ask for the BitLocker recovery key before some tools, including System Restore and Point-in-time restore, can run. Check where your key is now, while everything works:

  • Personal Microsoft account: sign in from another device at aka.ms/myrecoverykey.
  • Work or school account: sign in at aka.ms/aadrecoverykey, or ask your IT department.
  • Other places: a printout or a USB flash drive, if you saved the key that way when BitLocker was turned on.

Treat the key like a password: keep it private, and store any copy somewhere secure and separate from the PC.

06

Full system images

A system-image backup saves a broader copy of Windows and the system partitions it needs, so you can restore the PC as a whole. Whether other drives or data are included depends on the tool and how you set it up.

Protects
Windows, installed apps, settings, and files on the imaged partitions
Stored
An external drive, a network location, or other media you choose
Personal files
Included when they’re on a drive in the image
You need
A backup tool, enough storage, and a way to start recovery
Useful when
A drive fails or is replaced and you want the whole system back, not just files

Built-in option: Backup and Restore (Windows 7)

Microsoft lists System Image Backup as deprecated. It’s no longer being actively developed and might be removed in a future update. Microsoft’s current Windows 11 guidance still describes it, so check whether it’s available on your PC.

  1. Connect an external drive with enough free space, or have a network location ready.
  2. Open Control Panel → System and Security → Backup and Restore (Windows 7). You can also search Control Panel for Backup and Restore.
  3. Select Create a system image.
  4. Choose where to save it: a hard disk, one or more DVDs, or a network location. Then follow the steps.

Microsoft’s support pages list System Image Recovery among the Windows Recovery Environment tools for restoring an image. Check that you can find it before you rely on the image. Restoring an image replaces the current contents of the restored drives, so copy newer files elsewhere first if you can.

Third-party backup tools

For full-disk backups, Microsoft suggests looking at a product from another software publisher. Winwise doesn’t recommend a specific product. Before you choose one, check its current Windows 11 support, how recovery works (including whether you need to create its own recovery media), and its pricing and terms.

Whichever tool you use, confirm that the backup completed, and make sure you know how you would start a recovery before you need it.

07

When Windows needs recovery

Windows Recovery Environment (Windows RE) is a set of recovery tools that runs outside normal Windows. If Windows fails to start correctly several times, it opens Windows RE automatically.

Open Windows RE

  • From Windows, go to Settings → System → Recovery, and next to Advanced startup, select Restart now.
  • Or hold Shift while you select Power → Restart. This also works from the sign-in screen.
Can’t reach the sign-in screen?

Only when normal startup is already failing: turn the PC on and wait for the Windows or manufacturer logo, then hold the power button until it shuts down. Repeat this once more. On the third start, let it continue; Windows should show Automatic Repair. Select Advanced options. Don’t interrupt the PC while it’s installing an update or running a restore. You can also start from a Recovery Drive, or from Windows installation media and select Repair my PC.

If the device is encrypted, have your BitLocker recovery key ready; Windows RE may ask for it.

System Restore

Troubleshoot → Advanced options → System Restore

  1. Choose a restore point. Select Show more restore points if needed.
  2. Optionally scan for affected programs, then select Next → Finish.
  3. Let the restore complete, then restart.

Personal files aren’t affected. System changes made after the point are undone, which can affect recently installed apps, drivers, and updates.

Point-in-time restore

Troubleshoot → Point-in-time restore

Everything on the Windows volume returns to the selected point. Local files, apps, settings, and passwords changed after it are lost. If you can still reach important files created after that point, copy them to another drive or to cloud storage first.

  1. Enter your BitLocker recovery key if asked, then choose a restore point.
  2. Select Continue, review the restore point, Windows version, and data-loss warning, then select Restore.
  3. Keep the PC plugged in, and don’t turn it off until it restarts into Windows.

If Point-in-time restore isn’t available, or you need to go back further than about three days, Microsoft suggests System Restore instead.

Other recovery options (these aren’t backups)
  • Startup Repair in Windows RE tries to fix common problems that stop Windows from starting.
  • Uninstall updates (Troubleshoot → Advanced options) removes a recent update. Microsoft says your files and apps aren’t affected.
  • Fix problems using Windows Update (Settings → System → Recovery) reinstalls the current Windows version and keeps your apps, files, and settings. It needs an internet connection and may be unavailable on managed PCs.
  • Reset this PC reinstalls Windows. You can keep your personal files or remove everything; either way, apps and settings are removed.
