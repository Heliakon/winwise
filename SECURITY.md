# Security policy

Winwise generates PowerShell scripts that people run as Administrator, so a problem in the builder or in `src/script-template.ps1` can affect real PCs.

If you find a security issue, please report it privately with **Security → Report a vulnerability** on this repository instead of opening a public issue. Include the steps to reproduce it and the commit or release you tested.

Only the latest version on the `main` branch is supported.
